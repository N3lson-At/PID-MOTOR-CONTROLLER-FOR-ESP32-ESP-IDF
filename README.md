# PID-MOTOR-CONTROLLER-FOR-ESP32-ESP-IDF
Componente modular en ESP-IDF para control PID de motores DC en lazo cerrado. Incluye PID incremental con anti-windup, rampa de aceleración, filtro de media móvil y un sistema de seguridad en tiempo real para detección de atascamiento (stall) y sobre velocidad usando periféricos nativos (PCNT y LEDC).
